Password Safety

Create strong and unique passwords to protect your accounts.

What Makes a Strong Password?

  • Use a long password or passphrase.
  • Use different passwords for different accounts.
  • Include letters, numbers and symbols.
  • Avoid easily guessed personal information.
  • Enable two-factor authentication when available.

Phishing Awareness

Learn how to recognize suspicious emails, messages and links.

What is Phishing?

Phishing is an online scam where someone tries to trick you into revealing sensitive information or taking an unsafe action.

Common Warning Signs

👤

Unknown Sender

Be careful with unexpected messages from unknown senders.

🔗

Suspicious Links

Check links carefully before opening them.

⏰

Urgent Messages

Be careful when a message pressures you to act immediately.

🔑

Password or OTP

Never share passwords or verification codes unexpectedly.

⚠️ Safety Tip

If a message asks for sensitive information, verify the request using an official source.

🦠

Malware Awareness

Learn about common types of malicious software.

🦠

Virus

Malicious software that can spread through files.

🐴

Trojan

Software that may appear legitimate but can perform harmful actions.

👁️

Spyware

Software that can secretly collect information.

🔒

Ransomware

Malware that can restrict access to files or systems.

🛡️ Prevention Tips

  • Keep your software updated.
  • Download software from trusted sources.
  • Avoid unknown attachments.
  • Keep important files backed up.
  • Use reputable security software.
